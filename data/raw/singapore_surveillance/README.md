# Singapore Respiratory Surveillance Data

## Primary Source

Communicable Diseases Agency (CDA), Singapore.

## Data Product

Weekly Infectious Diseases Bulletins.

## Initial Outcome of Interest

Average daily polyclinic attendance for Upper Respiratory Tract Infection
(URTI), aggregated/reported by epidemiological week.

## Additional Candidate Variables

- Influenza surveillance activity
- Influenza positivity
- RSV activity, if consistently available
- SARS-CoV-2 activity, if consistently available

## Data Handling

Original source files will be preserved in this folder.

Raw files will never be manually edited.

Cleaning and transformation will be performed using reproducible scripts
and outputs will be written to data/interim/ and data/processed/.

## Provenance

For every downloaded file record:

- source
- URL
- publication year
- epidemiological week
- download date
- file name
